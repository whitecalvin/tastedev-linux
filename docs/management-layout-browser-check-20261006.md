# 현황 페이지 공통 레이아웃 확인

개발 브라우저에서 메뉴로 대시보드·데몬·로그·복구·보안·감사 경로를 이동하여 확인했다. 1280×720 뷰포트의 여섯 페이지 모두 상단 헤더 높이 56px, 문서 크기 1280×720으로 동일했다. 본문 `.management-body`는 높이 526px 및 overflow-y:auto를 유지했다. 대시보드 645px, 데몬 611px, 로그 1250px, 복구 794px, 보안 1494px의 콘텐츠는 본문 안에서 스크롤하고 감사의 현재 빈 목록은 스크롤이 필요하지 않았다. 확인 뒤 뷰포트를 원래 크기로 복원했다.

대시보드에서 서버 연결이 완료됐는데도 연결 요청 안내가 항상 표시되는 문제를 수정했다. 연결 상태에는 운영 권한 안내만 표시하고, 미연결 상태에는 기존 연결 안내를 유지한다. 새 짧은 안내에 기존 9개 번역 카탈로그의 번역을 추가했다. 실제 연결된 개발 화면에서 새 안내의 표시를 확인했다.

운영 서비스 제어, 설정 복원, 보안 정책 변경은 실행하지 않았다. 이번 증거는 화면 구조·스크롤·연결 상태 안내 범위이며 서비스 실행이나 전체 제품 완료 증거가 아니다.
