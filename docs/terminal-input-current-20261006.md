# 현재 개발 브라우저 터미널 입력 확인 (2026-10-06)

현재 개발 서버 `http://127.0.0.1:8787/terminal`에 별도 브라우저 탭으로 진입해 앱이 연 사용자 셸에서 `printf '입력확인 한글abc\n'`를 입력했다. 화면에서 명령의 한글·영문 echo, 출력 `입력확인 한글abc`, 다음 셸 프롬프트와 커서를 확인했다. 파일이나 운영 서비스 변경 명령은 사용하지 않았다.

증거 화면: `/tmp/tastedev-terminal-input-current-20261006.png`. 확인에 사용한 앱 터미널 탭을 닫아 셸을 종료하고 임시 브라우저 탭도 닫았다. 기존 사용자 브라우저 탭은 유지했다.

이 입력은 브라우저 자동화의 완성된 문자 입력이다. OS 입력기 한영 전환, 자모 입력, 받침 이동을 수행한 증거로 사용하지 않는다. 현재 코드의 xterm 조합 처리에는 별도 테스트가 있으나 실제 OS 입력기 수용 검사는 남아 있다. 실제 입력 오류가 재현되지 않아 이번 확인에서는 입력 코드를 변경하지 않았다.
