# PostgreSQL 적용 중단 안내와 같은 팝업 복구

실제 103번 GUI SIGKILL 검수에서 권한 오류가 아닌 프로세스 중단도 NOPASSWD 오류로 표시됐다. runHelper가 실제 종료 signal 및 sudo가 전달하는 stderr 없는 137/143 종료 코드를 HTTP 503과 한국어 결과 미확정 안내로 처리하도록 수정했다. 정상 helper 오류 프로토콜과 실제 권한 거부는 기존 상태 코드를 유지한다.

PostgreSQL 적용 요청에 응답 오류가 나면 적용 성공/원복을 단정하지 않고, 같은 검수 팝업에 현재 파일 경로의 중단 기록 조회·명시 복구 컴포넌트를 표시한다. 자동 복구나 재적용은 하지 않는다. 대상/정책/연결 변경 시 이전 화면과 승인·응답을 폐기한다. 복구 완료 메시지는 유지하고 이전 적용 승인을 소모한다.

실제 자식 SIGKILL 및 sudo 형태 137 종료 전달, 기존 helper 프로토콜, 컴포넌트 중복 실행/늦은 응답/대상 변경/복구 완료, 인증·권한·origin API 검사 28개 성공. 현재 396개 소스 SHA 일치 Next.js 운영 빌드 성공. 첫 빌드 임시 공간 할당량 실패를 보존하고 이전 자체 .next 산출물만 정리한 뒤 재확인했다.

이번 팝업 변경의 실제 브라우저 재검수는 아직 하지 않았다. 직전 native 복구 성공은 이 UI 수정 이전 증거이므로 현재 팝업 검수로 확대하지 않는다. 증거: .runtime/verification/postgresql-interrupted-guidance-20261008/result.json.
