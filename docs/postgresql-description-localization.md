# PostgreSQL 설정 설명

파일 설정 GUI는 UI 언어에 맞는 PostgreSQL 설명을 설정 이름으로 조회한다.
원본 주석은 접힌 별도 항목에서 확인하며 번역 설명이 파일을 수정하지 않는다.
검색은 설정 이름·값·원본 주석·현재 언어의 설명을 함께 검색한다.
기존 설정값 입력과 새 항목 이름 입력에는 현재 언어 설명을 aria-description으로
연결한다. 새 항목 이름을 입력하면 해당 설정의 설명을 즉시 보여주며, 언어를
바꾸면 설명도 갱신된다. 도움말 조회와 언어 변경만으로 파일 초안을 수정하지 않는다.

PostgreSQL 18.6의 `postgres --describe-config`에서 348개 항목을 추출했다.
한국어·영어·일본어·중국어·스페인어·프랑스어·독일어·러시아어·포르투갈어·
아랍어의 10개 UI 언어 모두 가져온 348개 항목 전체에 설명을 제공한다.
공식 번역에서 빠진 항목은 애플리케이션 작성 설명으로 보완한다.
모든 언어의 설명 누락 여부는 전체 가져오기 목록을 대상으로 검증한다.
`include`, `include_if_exists`, `include_dir`는 10개 UI 언어 모두 설명을 제공한다.
지역 언어 코드(예: ko-KR, pt-BR)는 기본 언어 설명을 사용한다.
설정 이름은 대소문자를 구분하지 않고 설명을 조회한다. 예를 들어 `datestyle`과
`DateStyle`은 같은 설명을 사용하며, 파일에 작성된 원래 이름은 변경하지 않는다.

현재 UI에서 번역을 제공하지 않는 언어는 영어 보충 설명으로 표시하며
`lang="en"`을 사용한다. 알 수 없는 확장 설정은 설명 미제공을 안내한다.
모든 Linux 로캘의 완전한 번역이나 모든 확장 모듈의 설명을 제공하는 상태는 아니다.
이 목록은 도움말 전용이며 설치된 서버의 기본값·범위·재시작 필요 여부를
임의로 덮어쓰지 않는다.

원본 파일 SHA-256과 번역 수는 `lib/locales/postgresql-descriptions.sources.json`,
라이선스는 같은 디렉터리의 `POSTGRESQL-LICENSE.txt`에 기록했다.
재생성: `python3 scripts/import-postgresql-descriptions.py POSTGRES_BINARY PO_DIRECTORY`.
해당 작업은 실행 중인 데이터베이스에 접속하거나 설정을 변경하지 않는다.

PostgreSQL 18의 삽입 기반 자동 VACUUM 비율은 테이블의 동결되지 않은 페이지를
기준으로 설명하도록 공식 짧은 설명을 보완했다.
참고: https://www.postgresql.org/docs/18/runtime-config-vacuum.html
파일 포함 지시문: https://www.postgresql.org/docs/18/config-setting.html


`pg_hba.conf` 접속 규칙의 6개 필드, 연결 유형 6개 및 인증 방식 15개도 동일한
10개 UI 언어로 설명합니다. 선택한 유형과 방식의 설명을 입력 바로 아래 표시하고
보조 기술에서 읽을 수 있도록 aria-description을 제공합니다. 지역 로캘은 기본
언어 설명을 사용하며 미지원 언어는 lang=en 영어 설명을 사용합니다.
PostgreSQL 키워드와 파일 원문은 번역하지 않습니다. 이 도움말은 해당 서버의
인증 방식 설치/지원 여부를 증명하지 않습니다. SSPI는 Windows 전용으로 안내합니다.
작성 기준: https://www.postgresql.org/docs/18/auth-pg-hba-conf.html


## 추가 공식 번역 언어 (2026-10-05)

설정 설명은 UI 전체 번역 여부와 별도로 선택한 기본 언어를 사용합니다.
추가 언어: 인도네시아어(id), 이탈리아어(it), 조지아어(ka), 폴란드어(pl),
스웨덴어(sv), 터키어(tr), 우크라이나어(uk). 공식 PostgreSQL REL_18_STABLE
PO 자료의 완전한 설명만 가져왔으며 fuzzy 항목과 일부 문단만 번역된 항목은
번역 완료로 표시하지 않습니다. 파일 SHA-256과 가져온 항목 수는 기존 source
manifest에 기록했습니다. 파일 포함 지시문 3개는 추가 7개 언어도 제공합니다.
스웨덴어와 우크라이나어는 누락을 보완하여 348개 설정 설명을 모두 제공합니다.
나머지 추가 언어의 공식 설명 범위는 id 139, it 236, ka 182, pl 158, tr 150개입니다.
미번역 항목은 해당 언어의 영어 보충 설명 안내와 lang=en으로 표시합니다.
새 항목 입력 도움말과 번역 설명 검색도 동일하게 동작합니다.
추가 7개 언어의 전체 UI 문구 번역은 아직 완료되지 않았습니다.

기존 영어 목록과 번역을 보존하면서 추가 PO 파일을 병합하는 명령:
`python3 scripts/import-postgresql-descriptions.py --merge-existing PO_DIRECTORY`.
이 명령은 실행 중인 PostgreSQL에 접속하거나 서버 바이너리를 실행하지 않습니다.


## 접속 규칙 설명의 17개 언어 지원

pg_hba.conf 도움말 27개(필드 6개, 연결 유형 6개, 인증 방식 15개)를 추가
7개 언어에도 제공합니다. 총 17개 언어 모두 동일한 키 목록을 설명합니다.
앱 작성 번역이며 PostgreSQL 18의 공식 pg_hba.conf 문서에 따라 작성했습니다.
규칙은 첫 일치 항목만 사용하고 인증 실패 시 다음 항목을 시도하지 않음을 설명하며,
local·peer의 Unix 소켓 범위, SSL/TLS·GSSAPI 범위, MD5 폐기 예정 및
Windows 전용 SSPI도 구분합니다. 인증 방식 이름과 실제 설정 원문은 그대로 유지합니다.
언어 변경 시 입력 아래 설명과 aria-description도 변경되며 파일 초안을 수정하지 않습니다.
이 변경은 17개 언어의 전체 UI 번역이나 모든 Linux 로캘 번역 완료를 의미하지 않습니다.


## 이탈리아어 전체 설정 설명과 행 보안 도움말 보완

이탈리아어 공식 번역에서 빠진 설정 112개는 앱 작성 번역으로 보완했습니다.
348개 설정 및 포함 지시문 3개를 모두 설명합니다. 경계값 0/-1, 빈 문자열의 의미,
트랜잭션·WAL·TLS 적용 범위도 설명하며 서버의 설정값 자체는 바꾸지 않습니다.
기존 공식 번역의 수와 SHA는 변경하지 않습니다. VACUUM 삽입 비율은 동결되지
않은 페이지를 기준으로 설명합니다. 설명 검색은 보완 번역도 포함합니다.

row_security 설명은 17개 언어 모두 on/off의 차이와 슈퍼유저·BYPASSRLS 예외를
명시합니다. off는 행 접근 제한을 풀어주는 설정이 아니라 정책이 적용될 쿼리를
실패시키는 설정입니다. 짧은 공식 설명을 그대로 옮겨 생길 수 있는 오해를 보완했습니다.
참고: https://www.postgresql.org/docs/18/runtime-config-client.html#GUC-ROW-SECURITY

## 언어 선택의 첫 화면 SSR (2026-10-06)

루트 레이아웃은 linux-language 쿠키를 우선 사용하고, 없으면 Accept-Language의 가중치로 초기 언어를 선택합니다. 클라이언트 Provider는 서버의 초기 언어로 시작합니다. 기존 localStorage 선택은 쿠키가 없는 경우에만 이전하므로, 저장된 서버 언어를 오래된 브라우저 값이 덮어쓰지 않습니다. 언어 선택은 쿠키와 브라우저 저장소에 함께 기록되며 언어와 RTL 방향을 첫 HTML에 반영합니다. 첫 방문에서 브라우저에만 남은 과거 설정을 이전할 때는 한 차례 언어 변경이 있을 수 있으나 이후 요청은 SSR로 표시합니다.
