# nginx 초기 상태 응답 무효화 수정

실제 개발 브라우저에서 nginx IDE로 이동한 후 정상 서비스 상태 응답이 '이전 연결의 응답입니다. 다시 조회하세요.' 오류로 처리되어 헤더에 '확인 불가'가 표시되는 문제를 확인했다.

ServerManager 하위 NginxToolbar의 effect가 요청을 시작한 뒤 상위의 mount effect가 revision을 증가시키는 순서가 원인이었다. 연결 식별자 변경은 렌더 시점에 감지하여 revision을 증가시키고 초기 mount effect에서는 불필요한 증가를 제거했다. 연결 변경 및 unmount cleanup의 기존 늦은 응답 무효화는 유지했다.

관련 검사 5개가 성공했다. 새 회귀 검사는 부모 mount effect 실행 이전에 시작한 하위 상태 요청의 성공과 실제 연결 변경 후 이전 요청의 거부를 확인한다. 실제 개발 페이지를 다시 로드해 '실행 중' 표시와 '확인 불가' 부재를 확인했다. 운영 서비스 시작·종료·설정 변경은 실행하지 않았다.
