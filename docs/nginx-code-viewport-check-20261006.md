# nginx 코드 표시 높이 수정

실행 중인 개발 화면 `http://127.0.0.1:8787/ide/packages/nginx`에서 nginx.conf를 선택하고 코드 보기 탭을 확인했다. 공통 pre 최대 높이 300px가 문법 강조와 행 번호에 적용되어 편집 textarea의 실제 높이 1066px와 달랐다. 이 때문에 13행 이후의 코드 표시가 화면 중간에서 잘렸다.

`app/globals.css`의 nginx 코드 편집기 내부 문법 강조와 행 번호에만 `max-height: none`을 적용했다. 개발 서버의 스타일 갱신 후 세 요소의 실제 높이가 모두 1066px임을 브라우저 DOM에서 확인했고 화면 아래까지 코드가 표시되는 스크린샷을 저장했다. 코드 영역을 아래로 스크롤했을 때 textarea, 문법 강조, 행 번호의 scrollTop이 모두 848px로 일치했다.

운영 설정 파일, 서비스, 계정과 배포 산출물은 변경하지 않았다. 이 확인은 현재 개발 화면의 코드 표시 및 스크롤 범위에 한정한다. 전체 제품 완료를 의미하지 않는다.
