## 공통 패키지 IDE 너비 조절 (2026-10-09)

트리뷰가 있는 패키지 IDE는 `components/ui/ide-split-layout.jsx`를 사용한다.
직접 자식인 `<aside className="nginx-tree-panel">` 뒤에 공통 분할 구분선이 들어가고 나머지 본문은 남은 공간을 채운다.
nginx, 공통 패키지 설정(Certbot·PostgreSQL·MariaDB·Redis), Node.js에 적용했다. 신규 패키지도 이 공통 레이아웃을 사용한다.

### nginx 포함 파일의 새 server 블록

`conf.d/*.conf` 및 HTTP 포함 문맥으로 확인된 편집 가능한 파일 노드 옆에 테두리 없는 `＋` 버튼을 제공한다. 긴 파일명은 줄임표로 표시하고 버튼은 노드 오른쪽에 고정한다. 파일의 우클릭 메뉴에서도 같은 동작을 제공한다.
파일 루트에 `server { }` 초안을 추가하고 새 노드를 선택한다. 기존 http 블록 버튼은 해당 http 자식으로 추가한다. 오류 파일·조회 전용 심볼릭 링크·HTTP 이외 포함 문맥에는 파일 추가 버튼을 표시하지 않는다. 운영 파일 적용은 별도 검토 절차를 유지한다.
개발 화면에서 conf.d/vhost_sap.conf 파일 버튼 → 새 server 노드 → 코드 보기 → `server { }` → 실행 취소를 확인했다. 검수 중 운영 파일은 변경하지 않았다.
