# MariaDB 백업·복원 화면의 연결 문맥 (2026-10-06)

한국어 기능 완성을 우선한다. 현재 MariaDB 백업은 설정 파일 백업이며 DB 내용 백업이 아니다. 데이터 덤프·복원은 이번 변경에 포함하지 않는다.

API 연결·접속 상태·설정 main·사용 가능 권한 변경 때 effect 정리 전에 이전 복원 검토/확인/결과/오류를 숨기고 이전 handler의 제출을 차단한다. 조회 응답과 목록은 시작한 연결에 연결된다. main만 바뀌면 백업 목록을 유지하되 이전 복원 검토는 폐기한다.

목록 조회, 검토, 현재 파일 백업, 복원은 하나의 실행 중 요청 보호를 공유한다. 확인은 복원 시작 시 즉시 소비하므로 동일 확인으로 두 번 실행할 수 없다. 부모의 disabled 표시 변경은 이미 실행 중인 동일 연결의 정상 완료를 무효화하지 않는다. 연결 변경 후 완료된 복원은 새 화면의 갱신 callback을 실행하지 않는다.

새 JSX 컴파일 회귀 5개, 기존 복원 컴포넌트 1개 및 적용 화면/설정 트랜잭션 15개, 총 21개 통과했다. 기존 단일 렌더 fixture가 추가 상태 초기값을 무시해 실패했던 원인은 fixture에서 useState 초기값을 유지하도록 고쳤다. 증거: `.runtime/verification/mariadb-backup-context-20261006/result.json`.

실제 설치 권한 helper/브라우저 전체 흐름 및 DB 내용 백업·복원 수용은 남아 있다. 최종 배포 검증은 실행하지 않았다.

최종 변경 소스 373개 Next.js 빌드 성공. 빌드 도중 소스 변경 없음: `.runtime/verification/source-build-2026-10-06T08-55-23.298Z/result.json`. 이전 08:54 빌드는 확인 재사용 차단 추가 이전 상태다.
