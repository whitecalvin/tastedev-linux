# 최신 소스 운영 빌드·HTTP 연동 확인 — 2026-10-06

최근 운영 작업 감사, 설치·인증서 종료 감사, 터미널 종료 감사 변경을 포함한 소스 353개를 임시 디렉터리에 복사하여 Next.js 운영 빌드를 수행했다. 빌드 중 원본 소스 변경은 없었고 빌드는 성공했다.

- 11개 보호 페이지의 비인증 로그인 이동 및 인증 후 렌더링.

- 실제 저장 세션의 시간 만료 후 API 차단·페이지 로그인 이동, query 보존, 재로그인 원래 화면 복귀, 로그아웃.
- 외부 Origin 변경 요청과 외부 로그인 복귀 URL 거부.

- Certbot nginx/webroot/standalone 선택 명령 미리보기. 실제 인증서 발급 없음.

최초 제한 환경에서는 localhost 포트 할당이 완료되지 않아 검사가 시작되지 않았다. 임시 localhost 서버 실행 권한을 확보한 재실행에서 위 검사를 수행했다. 임시 서버·계정·런타임은 종료·정리했다. 사용자 개발 서버, OS 계정, sudo 정책, 운영 서비스 및 설치 패키지는 변경하지 않았다.

이 증거는 HTTP 연동 범위다. 실제 설치·ACME 발급·운영 설정 적용과 복구·Tauri 창·OS 입력기 조합·모든 Linux 언어 번역을 완료한 증거는 아니다. 전체 목표는 미완료다.

당시 발견했던 인증서 완료 작업의 메모리 전용 조회는 이후 저장 파일 조회로 보완했다. 최신 356개 소스 빌드에서 실제 HTTP 재시작 조회도 확인했다: `docs/certificate-history-production-20261006.md`. 위 353개 빌드의 증거와 구분한다.
