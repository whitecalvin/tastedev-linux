# nginx 미반영 입력 유지

설정 행의 미반영 입력을 nginx 트리의 메모리 저장소에 유지하도록 연결했다. 파일 경로와 정확한 초안 원문별로 분리하고 행 ID·라벨·추가 항목 여부별로 구분한다. 원문이 바뀌면 이전 입력을 폐기하고, 연결 해제 시 전체 저장소를 비운다. 최대 16개 파일로 제한한다. 입력 원래 값으로 복귀하면 해당 미반영 기록을 제거한다. 영구 저장이나 운영 반영은 하지 않는다.

실제 개발 브라우저에서 worker_processes에 4를 입력한 뒤 코드 보기→설정 전환 후 값 4를 확인했다. 내용 비우기로 빈 값이 된 상태에서도 같은 탭 전환 뒤 빈 값과 행이 유지됐다. 확인 뒤 auto로 돌려 검사용 입력을 정리했다. 관련 검사 7개가 성공했으며 재마운트 후 빈 값 유지와 원문 변경 시 이전 입력 무효화를 포함한다.

구현 중 useRef import 누락으로 개발 화면 오류가 발생했고 import를 수정한 뒤 다시 로드하여 정상 동작을 확인했다. 운영 파일·서비스·배포 산출물은 변경하지 않았다. 새로고침/로그아웃 후 미반영 입력을 복원하는 영구 보존 기능은 아니다.
