# 인증서 완료 기록 저장 보완 — 2026-10-06

인증서 명령 실행 전에 새 완료 기록 폴더가 현재 사용자 소유의 700 경로이며 링크 경로가 아닌지 확인한다. Linux 권한을 지원하지 않는 저장소에서는 완료 기록을 보호할 수 있는 것처럼 진행하지 않는다.

완료 기록은 형식 검사 후 개인 임시 파일에 저장하고 fsync를 수행한다. 작업 ID별 배타적 공개 잠금으로 중복 저장을 차단하며, 기존 완료 기록을 덮어쓰지 않는다. 임시 파일을 rename하여 공개하고 디렉터리를 fsync한다. 정상 처리와 예외 후 임시 파일·열린 핸들을 정리한다. 실행 도중 프로세스가 강제 종료되어 남은 공개 잠금은 자동 삭제하지 않는다. 공개 이전의 불완전 임시 파일은 완료 기록 목록에서 제외한다.

Certbot 종료 콜백과 동기 실행 시작 실패 기록 모두 같은 저장 함수를 사용한다. 증거 저장이 실패하면 기존 운영 작업 잠금은 보존한다.

검증: `node --test --test-isolation=none tests/admin-job-record.test.mjs tests/async-operation-audit.test.mjs tests/admin-job-api.test.mjs` 12개 통과. 실제 임시 파일의 두 동시 저장 중 하나만 성공하고 기존 결과가 유지되는지, 권한이 열린 폴더 거부, 별도 프로세스 조회, 작업 종료 및 감사 오류 경로를 확인했다. 실제 Certbot 명령, 운영 서비스 변경, 강제 종료 시점별 crash injection은 수행하지 않았다.

전체 제품 및 최종 배포 완료를 뜻하지 않는다. 운영 빌드·HTTP 연동 증거는 이번 기록 저장 변경 이전 소스다.
