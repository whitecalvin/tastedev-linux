# 현재 개발 웹 터미널 실사용 흐름 확인

실제 /terminal 화면의 새 터미널 버튼으로 별도 시험 세션을 생성했다. 기본 계정의 Bash 프롬프트에서 printf로 English 및 완성된 한글 문자열이 입력·출력되고 프롬프트로 복귀했다. 터미널 1 → 2 전환 후 출력 유지 확인.

자동 입력 도구의 긴 연속 입력은 deadline을 초과하여 중간 명령줄이 남았다. 해당 시험 세션만 닫고 새 세션에서 짧은 명령 `printf '%s\n' {1..150}`을 실행했다. 150줄 출력과 탭 전환 후 `echo TAB_SWITCH_OK` 입력·출력, 이전 출력 스크롤을 확인했다. 시간 초과를 앱 자체의 입력 실패라고 판정하지 않는다.

1280×720에서 document 크기는 동일했다. terminal host는 x=48, width=1232이며 xterm6 내부 vertical scrollbar의 오른쪽 끝 x=1280이 컨테이너 오른쪽 끝과 일치했다. 콘솔 오류 없음.

OS 입력기로 자모를 조합한 검사는 아니며 완성된 한글 텍스트 전달 검사다. 두 시험 세션을 닫았고 기존 터미널 1은 보존했다. 브라우저 시험 탭 정리 완료. 화면: /tmp/tastedev-terminal-input-browser.jpg.
