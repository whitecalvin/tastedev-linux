# GUI 설정 파일 전환 입력 보호

사용자의 한국어 우선 개발 요구에 따라 기존 한국어 입력과 안내를 유지한다.

공통 FileSettings 화면의 이전 행 입력·미완성 값·추가 이벤트는 이전 record.text를 캡처하지만 부모 패치 콜백이 현재 파일을 읽으므로 파일 전환 뒤 잘못 전달될 수 있었다. 실제 컴포넌트를 Next SWC로 컴파일한 재현 검사에서 새 파일 선택 뒤 변경 콜백이 3회 전달되어 기대 1회와 달랐다.

현재 파일 레코드·설정 형식·선택 그룹과 마운트 상태를 확인한 뒤에만 입력을 전달한다. 파일 전환, 같은 파일 코드 변경, 형식 변경, 화면 종료 후 이전 이벤트를 차단한다. 기존 미완성 입력 유지, 행별 수정, 중복 행, 값 비우기, 비밀번호 가림과 한국어 설명 검색은 유지한다.

관련 검사 8개 통과. 실제 브라우저와 운영 적용 확인은 이번 수정에서 수행하지 않았다. 증거는 `.runtime/verification/file-settings-context-20261007/result.json`이다.
