# PostgreSQL 기본 설정 GUI 대조 (2026-10-06)

설치된 PostgreSQL 18.6의 `postgresql.conf.sample`을 GUI 파서로 읽고, 같은 실행 파일의 `--describe-config` 목록과 대조했다. 서버 실행 및 DB 접속 없이 수행했다.

- 기본 파일의 351개 설정 항목을 순서대로 읽었다.
- 모든 항목이 실행 파일의 설정 목록 또는 include 구문에 해당한다. 이름 대조는 PostgreSQL의 대소문자 처리에 맞춰 수행했다.
- 구문 오류로 표시되는 값은 없다.
- `shared_buffers`를 메모리에서 수정했을 때 해당 줄만 변경되고 나머지 줄은 보존됐다.
- 시스템 설정 파일을 저장하거나 서비스를 변경하지 않았다.

실행 파일 및 기본 파일 SHA-256은 같은 이름의 JSON 증거에 기록했다. 이 확인은 기본 설정 파서 및 단일 항목 편집 범위이며, 실제 서비스 적용·복원·모든 설정의 의미적 유효성이나 전체 제품 완료를 증명하지 않는다.
