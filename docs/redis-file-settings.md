# Redis 파일 설정 GUI

도구의 설치된 Redis 패키지를 선택하고 트리에서 `redis.conf` 또는 `설정` 노드를 선택합니다. 오른쪽 설정 화면은 같은 파일 코드 초안의 지시어를 원래 순서대로 보여 줍니다. 연결·메모리·AOF 그룹의 주요 항목 폼도 같은 초안을 사용합니다.

- 활성 지시어는 이름에 관계없이 표시합니다. 반복된 `save`, `client-output-buffer-limit` 등은 행별로 편집합니다.
- 알려진 지시어의 주석 처리 예시도 표시합니다. Redis 7.0 공식 설정 레지스트리의 이름·별칭을 사용해 설명 문장과 구분합니다. 이후 버전이나 모듈의 알 수 없는 주석 처리 항목은 코드 보기에서 확인할 수 있습니다.
- 값은 여러 인수와 따옴표를 포함한 원문으로 입력합니다. Redis는 줄 전체가 `#`로 시작하는 경우를 주석으로 처리합니다. 줄 끝의 `#`를 GUI가 잘라 내지 않습니다.
- 비우기는 행을 삭제하지 않고 값을 비워 해당 행을 주석 처리합니다. `save ""`처럼 빈 문자열 인수를 지정하는 것과는 다른 동작입니다. 기존 기본값이나 다른 같은 이름의 항목에 미치는 의미는 Redis 검수로 확인해야 합니다.
- 활성화 스위치는 선택한 행만 주석 처리하거나 해제합니다. 비어 있는 값은 활성화하지 않습니다.
- `requirepass`와 `masterauth` 입력은 비밀번호 형식으로 표시합니다. 파일 원문은 기존 인증된 코드 보기에서 확인할 수 있습니다.
- 설정 검색, 새 지시어 추가, 코드 순서 변경, CRLF 및 관계없는 지시어 보존을 지원합니다. 오래된 행이나 줄바꿈 주입, 닫히지 않은 따옴표와 UTF-8 크기 제한 초과는 거부합니다.

행 편집은 로컬 구문을 검사하고 초안을 갱신합니다. Redis 버전·모듈별 값의 의미와 운영 적용 가능성을 검증한 것은 아닙니다. 기존 운영 적용 경로의 지원 항목·검토·권한 제한은 유지합니다. 임의 지시어 초안을 자동으로 운영 파일에 적용하지 않습니다.

참조: [Redis 공식 설정 sample](https://github.com/redis/redis/blob/7.0/redis.conf), [설정 로더](https://github.com/redis/redis/blob/7.0/src/config.c), [인수 구문 파서](https://github.com/redis/redis/blob/7.0/src/sds.c).
