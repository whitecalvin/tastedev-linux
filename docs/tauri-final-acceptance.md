# 설치 Tauri GUI 최종 확인

2026-10-09. 현재 확인 도구는 브라우저만 제어하며 네이티브 Tauri 창 제어는 제공하지 않습니다. 사용자의 실제 설치 앱 직접 확인을 별도로 기록합니다. 기존 웹/native 기능 검수 및 사용자가 확인한 Tauri 한글·한영 전환 결과를 반복하지 않습니다.

## 확인할 흐름

1. 설치된 LINUX Server IDE 앱에서 로그인 화면을 열고 로그인합니다. 설치 주소는 127.0.0.1:8791이며 개발 주소 8787과 구분합니다.
2. 현황 → 대시보드·데몬·로그·복구·보안·감사·설정으로 이동합니다. 공통 헤더와 왼쪽 메뉴가 유지되고 내용 영역만 스크롤되는지 확인합니다.
3. 패키지 설치에서 검색 후 초기화합니다. 설치 실행은 필요하지 않습니다.
4. 도구 → 설치된 nginx·Certbot·PostgreSQL을 선택합니다. 해당 패키지 트리와 설정 화면이 열리는지 확인합니다.
5. nginx 파일 → http → server 등의 노드를 선택하고 설정/코드 보기를 전환합니다. 코드 영역이 남은 높이를 채우고 트리가 오른쪽 스크롤에 따라 움직이지 않는지 확인합니다.
6. 편집 없이 다른 메뉴로 이동했다가 돌아와 정상 화면을 확인합니다. API 모델 갱신·분석·설정 적용·서비스 시작/종료는 이 확인에 포함하지 않습니다.
7. 문제가 있으면 페이지와 증상만 알려주세요. 계정 비밀번호와 API 키는 보내지 않습니다.

직접 확인 전 상태: 사용자 확인 대기. 이전 사용자 한글 입력·한영 전환 확인은 완료이며 이 문서는 전체 제품 합격을 주장하지 않습니다.

## 현재 소스 대조

- src-tauri/tauri.conf.json: 개발 8787, 설치 frontendDist 8791, 최소 창 720×600.
- src-tauri/Cargo.toml: 설치 custom-protocol feature 제공.
- packaging/tastedev-linux.service: 8791 loopback, 별도 설치 상태·인증 경로.
- 최신 소스 408개 운영 빌드 성공(IJEpvynamcuHVE1vxNPVO), 동일 빌드 HTTP 16개 그룹 성공. 103번 설치 Chrome에서 nginx 파일 추가 버튼과 트리 너비 조절도 확인했습니다. 이 결과는 Tauri 창 확인을 대신하지 않습니다.
- 실제 설치 모드 노화된 세션 GUI 갱신은 기존 독립 DB 증거 PASS. 실제 여러 날 경과 관측은 별도이며 없던 증거를 성공으로 쓰지 않습니다.

## 작업표시줄 아이콘 연결

Linux GTK 앱 ID를 `com.gxsoft.linux`로 활성화하고 설치 실행 항목을 `com.gxsoft.linux.desktop`으로 맞춥니다. `StartupWMClass`도 같은 값을 사용하며 `Icon=tastedev-linux`는 hicolor의 PNG/SVG 아이콘을 가리킵니다. 업데이트 후 기존 앱을 종료하고 다시 실행해야 합니다. 이전 실행 항목을 작업표시줄에 고정했다면 새 실행 항목으로 다시 고정해야 할 수 있습니다. 실제 작업표시줄 모양은 네이티브 GUI 검수로 별도 확인합니다.
