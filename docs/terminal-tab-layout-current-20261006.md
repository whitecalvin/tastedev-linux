# 터미널 탭 높이 및 좁은 화면 확인

실제 브라우저에서 터미널 탭이 19px로 축소되는 것을 확인했다. 공통 header의 중앙 정렬을 터미널에서는 stretch로 지정하고 탭·닫기 버튼을 32px로 명시했다. 도구 모음은 32px 콘텐츠와 1px 구분선이다. 탭 위의 여백은 없다.

1024×768: document 크기 동일, 왼쪽 rail 제외 터미널 너비 976px, 탭 32px, 탭 본문 높이 679px.
768×600: document 크기 동일, 터미널 본문 너비 720px, 탭·닫기 32px, 콘솔 오류 없음.
nginx 768×600 및 600×600: document가 viewport를 넘지 않고 트리·설정 컨테이너는 화면 안에 유지된다. 스크롤은 내부 영역에서 발생한다. 전체 모바일 상호작용 또는 OS IME 검사를 의미하지 않는다.

화면 증거: /tmp/tastedev-terminal-tabs-32px.jpg. 임시 브라우저 탭과 화면 크기 override는 정리했다.
