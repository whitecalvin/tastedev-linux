# 한국어 코드 편집·접속 규칙 검수 후속

한국어 개발 완료 후 다국어 확장을 진행한다는 사용자 우선순위를 유지한다.

코드 편집에서 이전 파일 또는 연결의 이벤트가 새 파일에 전달되는 문제를 재현한 후 수정했다. 이전 저장·비교 요청의 시작, 이전 입력의 전달, 권한 해제 후 저장 시작과 완료를 차단한다. 연결 교체 첫 렌더에서 이전 비교 결과를 숨긴다. 편집 위치 복원과 설정 동기화를 유지한다.

PostgreSQL pg_hba.conf 검수 결과의 16종 진단 코드를 한국어 원인과 확인 방법으로 표시한다. 알려지지 않은 진단에는 일반 한국어 안내를 사용하며 원시 진단 문자열을 설명으로 출력하지 않는다. API의 내부 코드는 유지한다.

관련 8개 테스트 파일의 14개 검사가 통과했다. Next SWC로 실제 컴포넌트를 컴파일한 검사와 정적 렌더링을 포함한다. 실제 브라우저, 운영 적용, 제품 전체 완료 또는 최종 배포를 증명하는 결과는 아니다.

증거: `.runtime/verification/korean-editor-hba-20261007/result.json`.

현재 384개 소스의 Next.js 빌드는 `.runtime/verification/source-build-2026-10-06T21-02-19.089Z/result.json`에 PASS 기록을 남겼다. 최초 임시 저장소 할당량 실패는 보존하고 자체 비활성 빌드 두 개만 증거 보존 후 정리했다.

동일 빌드의 실제 한국어 브라우저에서 코드 입력·설정 port 반영·다른 파일 선택 시 초안 확인·기존 초안 유지·편집기 컨테이너 채움·외부 스크롤 없음·로그아웃을 확인했다. 원본 fixture와 호스트 파일은 변경하지 않았다. 첫 크기 검사는 clientHeight가 스크롤바 높이를 제외하는 것을 반영하지 않아 FAIL 기록을 남겼다. 실제 테두리 높이로 수정한 후 재검사했다. 화면은 `.runtime/verification/postgresql-editor-smoke-20261007.png`에 보존했다.

이번 브라우저 확인은 코드 편집 흐름이다. PostgreSQL HBA 실제 검수·운영 적용을 증명하지 않는다. 관리자 실행 파일명 변경은 사용자가 직접 처리하기로 했으며 실제 검수 경로 확인은 남아 있다.

실제 PostgreSQL 18.6 단일 사용자 파서 후속: 유효한 포함 파일, 잘못된 인증 방식·CIDR·인증 옵션·필드 누락, 포함 파일 누락·순환 참조의 7개 흐름을 검사했다. 검수 함수와 실제 후보 파일 생성·PostgreSQL 실행·결과 파싱 및 한국어 설명 변환을 연결했다. 정상 포함 파일은 통과하고 잘못된 초안은 거부했다. 인증 옵션 비밀값을 결과에 포함하지 않으며 모든 검사에서 원본 fixture 바이트가 유지되었다. 임시 파일 정리도 수행했다.

실행 증거: `.runtime/verification/postgresql-hba-local-2026-10-06T21-05-52.198Z.json`. PostgreSQL 버전과 실행 바이너리 SHA-256을 함께 기록했다. 최초 실패는 누락 파일 진단의 기대 경로를 주 파일로 잘못 지정한 검사 오류였으며 `.runtime/verification/postgresql-hba-local-2026-10-06T21-05-38.325Z.json`에 보존했다. 누락 파일 경로로 수정한 뒤 재검사했다.

관리자 helper/root namespace 전송, GUI 검수 버튼, 운영 서비스 재시작, 실제 인증 접속 또는 배포는 이 단일 사용자 파서 확인에 포함되지 않는다.
