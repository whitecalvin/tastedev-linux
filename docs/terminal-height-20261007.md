# 터미널 상태바 경계 확인 (2026-10-07)

터미널 화면이 높이를 `100dvh - 56px`로 계산하여 하단 고정 상태바 26px 뒤까지 늘어나는 문제를 수정했다. 기본 및 좁은 화면 규칙에서 헤더와 상태바 높이를 함께 제외한다. 왼쪽 패널은 유지한다.

현재 8787 개발 서버의 실제 인증된 브라우저에서 확인했다. 1280×720에서 터미널 하단/상태바 상단은 모두 694px, 640×640에서는 모두 614px이다. 페이지 바깥 세로 스크롤은 없으며 데스크톱 xterm 스크롤 영역의 오른쪽은 컨테이너 오른쪽 1280px과 일치한다. 실제 PTY에서 한글 40줄을 출력하여 마지막 출력 및 프롬프트가 가려지지 않는 모습을 기록했다.

증거: `.runtime/verification/terminal-height-20261007/result.json`, `desktop.jpg`, `narrow.jpg`. 변경된 CSS SHA-256을 기록했다. OS 입력기의 한영 전환/자모 조합을 검증한 결과는 아니다. 검사 셸 종료 후 검사 탭을 닫으며 개발 서버는 유지한다.
