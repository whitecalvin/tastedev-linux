# 페이지 전환 성능 개선 — 2026-10-10

## 전체 속도 추가 점검

데몬 초기 조회에서 일반 systemctl 상태 조회와 PostgreSQL 클러스터 발견·상태 조회를 동시에 시작하도록 변경했다. 클러스터 탐색 실패는 즉시 처리하고, 기존 행 순서·부분 실패 표시·설정 경로 연결은 유지한다. 일반 서비스 조회가 완료되기 전에 클러스터 조회가 진행되는 검사를 포함해 관련 5개 파일의 9개 검사가 통과했다. 이 추가 변경의 실제 화면 지연 감소율은 측정하지 않았다. 103번 설치 반영은 아래 최신 배포 기록에서 확인한다. 기존 기능 분리·선택 언어 로딩·요청 내 조회 공유·묶음 패키지 조회 개선은 유지한다.

공통 ConsoleWorkspace의 기능 컴포넌트를 next/dynamic으로 분리했다. 대시보드 진입 시 nginx·DB IDE·터미널·보안·감사 기능 코드를 모두 정적으로 가져오지 않는다. 기능별 SSR은 유지한다.

consoleInitialData의 상태·보안·서비스 조회는 React cache로 동일 SSR 요청의 레이아웃/페이지 사이에서 공유한다. 요청이 달라지면 보안 정책은 다시 읽는다. getStatus의 독립 읽기는 병렬로 수행한다. SSR 인증과 초기 상태를 받은 embedded 화면은 마운트 직후 중복 인증 조회를 생략한다. 공통 셸의 세션 유지 검사 및 각 API의 401 로그인 이동은 유지한다.

공통 loading 경계와 아이콘/패키지 메뉴의 hover/focus prefetch를 추가했다. 브랜드도 Next Link로 이동한다. 디자인 변경과 운영 서버 설정 변경은 하지 않았다.

## 선택 언어 로딩 추가 개선

최종 빌드 성공: `build-language-split.log`. ConsoleWorkspace 참조 청크 합계는 원본 247,580 bytes / gzip 74,677 bytes로, 원래 배포 빌드 대비 gzip 약 92.3% 감소했다. 이는 해당 컴포넌트 청크 범위의 수치이며 전체 페이지 전송량·응답 속도의 감소율이 아니다. `bundle-language-split.json`, `result.json`에 범위를 기록했다.

관련 9개 검사 파일 통과. 언어 로딩 경합·실패·재시도 및 SSR 번역도 검사했다. 기존 전체 언어 번역 누락은 이 성능 변경의 완료 범위에 포함시키지 않았으며 그대로 미완료다.

실제 Chrome의 8787 인증 세션에서 대시보드·데몬·로그·언어 목록·nginx 트리 및 설정/코드 보기를 확인했다. 파일/설정 저장과 운영 명령은 실행하지 않았다. 개발 모드 최초 컴파일 중 일시 지연과 수정 중 Fast Refresh 전체 갱신이 관찰됐으며, 운영 빌드의 전환 속도로 추정하지 않았다. 브라우저 제어 도구에 Performance API가 노출되지 않아 정확한 브라우저 전환 시간은 기록하지 않았다.

## 패키지 IDE의 서비스 조회 범위 축소
