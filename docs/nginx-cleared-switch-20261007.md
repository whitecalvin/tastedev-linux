# nginx 스위치 내용 비우기 (2026-10-07)

설정 행의 내용 비우기는 행을 제거하거나 코드를 수정하지 않고 미반영 입력만 비우는 기존 동작을 유지한다.

이전에는 boolean 값이 빈 문자열이 되어도 스위치가 off처럼 표시되었다. 빈 상태에서는 같은 위치에 `값 선택 / on / off` 입력을 표시한다. on/off를 명시적으로 선택하면 스위치로 돌아온다. 비운 상태는 저장할 수 없고 노드·탭 재진입에도 동일한 입력 cache로 유지된다. 원래 값을 선택하면 미반영 입력이 해제된다.

## 확인

- 실제 JSX 컴파일 및 코드 편집/입력 보존 관련 20개 검사 통과. 원래 on/off 각각에 대해 비우기→재마운트→원래 값 선택/다른 값 선택→초안 반영을 검사했다. 코드 편집의 원본 변경 차단, 코드 roundtrip 순서 및 입력 cache 격리 회귀를 포함한다.
