# MariaDB 적용·복구 한국어 안내

설정 대상·후보 검수·서비스 실행 조건·백업 신뢰·중단 복구 경로의 영어 오류 안내 30곳을 한국어로 변경했다. 다음 조치를 설명하며 기존 HTTP 상태와 거부 조건, 비공개 native 진단 차단은 유지했다. 대상은 mariadb-service-scope, mariadb-config-hooks, mariadb-recovery, mariadb-recovery-backup 네 모듈이다. MariaDB 전체 안내와 다른 패키지의 한국어 개발 완료를 의미하지 않는다.

적용/복구/서비스/후보 검수 24개를 확인했다. sandbox UID 변환으로 권한 검사에 실패한 최초 결과와 영어 문구를 기대하던 기존 assertion 실패를 구분했다. 실제 UID 검사에서 기존 적용·원복·중단 기록 보존은 성공했고, 한국어 문구 기대값으로 고친 후보 검사 3개도 성공했다. native 진단의 비밀번호가 사용자 안내에 나타나지 않는 검사도 유지했다. 이번 변경으로 호스트 서비스를 실행하거나 변경하지 않았다.

다국어는 사용자 요청대로 한국어 개발 이후 별도 진행한다. 최종 배포 검수는 수행하지 않았다.
