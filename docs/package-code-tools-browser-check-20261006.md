# 공통 코드 편집 도구 개선

PostgreSQL 개발 IDE에서 큰 텍스트 버튼으로 남아 있던 다운로드·디스크 비교·작업 폴더 저장·편집 숨기기·다음 찾기를 공통 IconButton으로 변경했다. 번역된 aria-label/title을 유지하고 SVG는 선형 아이콘으로 표시한다. 실제 브라우저에서 다섯 버튼이 모두 32×32px, 테두리 0px임을 확인했다. 도구 배경은 투명하며 hover/focus 표시는 유지한다. 이 컴포넌트를 사용하는 다른 패키지 코드 화면에도 같은 도구가 적용된다.

코드 검색은 선택 범위만 바꾸고 스크롤하지 않아 화면 밖 검색 결과를 볼 수 없었다. 줄 높이와 편집 영역 높이를 기준으로 검색 결과 줄을 가운데에 배치하도록 수정했다. 실제 postgresql.conf 807행의 default_text_search_config를 검색하여 표시되는 것을 확인했고 textarea/문법 강조/행 번호의 scrollTop이 17290px로 일치했다. 원본 설정은 편집하거나 저장하지 않았다.

PostgreSQL 최초 진입과 Certbot 전환에서 왼쪽 트리와 '왼쪽 노드를 선택하세요.' 안내를 확인했다. PostgreSQL 코드 보기의 편집층·문법 강조·행 번호 높이는 동일했다. 현재 계정에서 pg_hba.conf 읽기가 거부되고 Certbot 인증서 디렉토리가 없는 상태도 확인했다. 계정 권한과 인증서 상태를 변경하지 않았다.

관련 기존 검사 6개(code-search, code-indent, package-config-ide-render)가 성공했다. 이는 운영 적용·인증서 발급이나 전체 제품 완료를 의미하지 않는다.
