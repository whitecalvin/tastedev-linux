# 인증서 작업 기록 목록·GUI — 2026-10-06

Certbot 설정 화면에 테두리 없는 작업 로그 아이콘을 추가했다. 팝업에서 완료 기록 목록을 조회하고, 선택한 작업의 명령·결과·로그를 읽는다. 기존 실행 중 작업 상태와 발급 입력값을 교체하거나 명령을 다시 실행하지 않는다. 새로고침과 닫기도 아이콘 버튼이다.

인증된 `admin-jobs` GET은 완료 기록 최대 100개의 ID·결과·시각만 반환한다. 탐색은 1000개 항목 및 읽기 합계 32MiB로 제한한다. 목록에서 로그·명령은 제외한다. 손상된 기록은 제외하고 제한 여부를 표시한다. 선택 로그 조회는 기존 `admin-job`의 파일 안전성 검사를 사용한다. 팝업을 닫거나 연결이 바뀌면 이전 조회 응답을 무시한다.

## 개발 파일시스템 확인

현재 프로젝트 SSD는 exFAT이며 `fmask=0000,dmask=0000`이다. `.runtime/server-tools`는 777로 표시되며 chmod 700이 성공 코드를 반환해도 실제 권한은 바뀌지 않았다. 이를 실제 stat와 브라우저 조회 실패로 확인했다. 안전성 검사를 완화하지 않았다.

새 인증서 완료 기록은 `LINUX_AUTH_ROOT`가 지정되면 그 아래 `certificate-jobs`에 저장한다. 지정되지 않으면 상태 저장소 아래 같은 폴더를 사용한다. Linux 파일시스템의 로그인 저장 경로를 개발 환경에서도 사용하게 하며 인증 DB 파일을 변경하지 않는다. 기존 `server-tools`의 안전한 기록도 ID 조회와 목록에서 호환 조회한다. 안전하지 않은 기존 저장소는 제외 경고를 표시하며 파일을 이동·삭제하지 않는다.

## 확인

저장 기록·별도 프로세스·비동기 작업·GUI·API 검사 12개 통과. 추가 기존 Certbot 선택·명령 검사도 통과했다. 실제 브라우저에서는 기록 팝업의 최초 exFAT 권한 오류와 새 저장 경로 적용 후 0건 목록/기존 저장소 제외 안내를 확인했다. 실제 완료 작업이 없으므로 브라우저에서 저장된 작업 선택은 확인하지 않았으며 해당 선택 흐름은 컴파일된 컴포넌트 검사에서 확인했다.
