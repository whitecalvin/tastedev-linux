# 일반 콘솔 첫 렌더링 SSR (2026-10-06)

대시보드·데몬·로그·복구·보안·감사·패키지·터미널 라우트는 requirePageSession 이후 공통 서버 상태와 보안 설정을 읽어 ConsoleWorkspace initialData에 전달한다. 기존 패키지 IDE와 동일한 공개 조회 데이터를 사용하며 키나 인증 저장 파일을 전달하지 않는다. 초기 상태가 있으면 기존 클라이언트 연결 코드가 status/security 중복 조회를 건너뛴다. 수동 새로고침과 세션 확인은 유지한다.

8개 라우트에서 인증 거부 시 metadata 조회가 실행되지 않고 허용 시 초기 props가 전달되는 검사와 기존 IDE/콘솔 검사 총 25개 성공.

실제 새 패키지 페이지 첫 AX 관측에서 작업 허용·호스트명·6개 패키지 설치 상태가 존재했다. 패키지·보안·감사 모두 연결 대기 문구 없음. 1280x720 문서 크기는 1280x720이며 패키지 management-body 안에서 740px 콘텐츠를 526px 영역으로 스크롤한다. 화면: /tmp/tastedev-packages-initial-ssr-20261006.jpg.

이 확인은 초기 렌더링/인증 순서/관측 페이지 레이아웃에 한정한다. 설치·설정 적용 및 전체 제품 완료를 뜻하지 않는다. DEB 검증은 하지 않았다.
