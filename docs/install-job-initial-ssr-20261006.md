# 설치 작업 첫 렌더링 복구 (2026-10-06)

ConsoleWorkspace의 job 초기값을 SSR status.job 또는 보존된 공통 상태 기록으로 연결했다. 이전에는 SSR 상태에 작업 기록이 있어도 job을 null로 시작해 진행 표시와 기존 로그가 숨겨지고 자동 추적도 시작되지 않았다.

실행 중 기록은 기존 polling으로 완료까지 추적하며 설치 완료 후 공통 상태를 갱신한다. 완료·실패 기록은 첫 렌더링부터 명령/로그와 함께 표시한다. 저장된 작업을 자동 재실행하지 않는다.

컴파일된 콘솔의 running/success/failed 첫 렌더링 상태·명령·로그 복구 및 세션/SSR/갱신 관련 테스트 12개 성공. 실제 패키지를 설치하거나 운영 작업 기록을 수정하지 않았다. 전체 제품 완료 증거가 아니다.
