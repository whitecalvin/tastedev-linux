# 한국어 개발: 공통 화면 세션 유지 (2026-10-07)

사용자 지시대로 한국어 기능·화면 개발을 우선한다. 추가 다국어 작업과 이름 변경, DEB 검증은 수행하지 않았다.

공통 레이아웃이 유지된 상태에서도 화면 사용 중 인증 쿠키를 갱신하도록 세션 모니터를 연결했다. 표시된 화면에서 최근 활동이 있을 때 최대 5분 간격으로 상태를 확인한다. 숨겨진 화면과 장시간 미사용 화면은 갱신하지 않는다. 인증 거부가 확인되면 현재 경로를 보존하여 로그인으로 이동한다. 네트워크 오류·저장소 오류는 로그아웃으로 오인하지 않는다. 중복 요청, 요청 시간 초과, 레이아웃 해제 후 늦은 응답도 처리한다.

HTTPS 보안 쿠키 설정의 실제 로그인 검사에서 기존 코드가 `linux_session`만 찾는 오류를 재현했다. Better Auth가 발급하는 `__Secure-linux_session`을 로그인·조회·갱신·로그아웃에서 동일하게 사용하도록 수정했다. 유사 이름과 중복 쿠키는 거부한다. 사용자 환경의 보안 설정은 변경하지 않았다. 이전 개발 화면의 로그인 이동 원인 전체가 이것으로 입증된 것은 아니다.
