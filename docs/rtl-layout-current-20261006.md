# 공통 화면 RTL 배치 (2026-10-06)

아랍어 방향에서 메뉴와 목록 구분선이 바깥쪽에 놓이고, 켜진 스위치 손잡이가 트랙을 벗어나는 문제를 수정했다. 구분선은 inline-end를 사용하고, 표/패키지 메뉴의 텍스트는 start 정렬을 사용한다. 인증서 기록과 서비스 목록의 좁은 화면 구분선 규칙도 함께 바꿨다. 코드와 설정 값의 LTR 방향은 유지한다.

아랍어 노드 선택 안내를 실제 오른쪽 트리 위치에 맞췄다. 프로젝트 이름 변경은 사용자가 직접 진행하므로 이번 변경에 포함하지 않는다.

증거: `.runtime/verification/rtl-layout-current-20261006/`. 실제 ConsoleChrome, Switch, NativeSelect, CustomSelect를 임시 SSR 화면에 렌더링하고 현재 CSS를 적용했다. RTL 1280×720 및 640×640에서 문서 전체 크기/내부 영역과 구분선을 확인했다. RTL 스위치를 실제 켜고 끄고, LTR 640×640의 두 스위치 상태에서도 손잡이가 트랙 내부임을 확인했다. 소스 SHA-256, 스크립트, 측정 JSON, 스크린샷을 보존했다. 원래 브라우저 언어 ko-KR을 복구했으며 임시 서버는 종료된 것을 확인하고 자체 생성 폴더를 정리했다.

이 화면의 본문/레이블은 fixture다. 운영 API, 설치된 앱 전체 RTL 흐름, CustomSelect hydration 및 펼침 동작 검사는 포함하지 않는다. viewport reset 직후 LTR 측정은 640×640이므로 넓은 LTR 검사로 해석하지 않는다. 자체 실패 탭 하나의 닫기는 브라우저 URL 정책으로 차단되었고 사용자 탭은 보존했다.

현재 번역 검사: 고정 UI 1102개, nginx 설명 195개, 사이트 오류 24개 누락 없음. 우크라이나어 351/1493개 및 나머지 미번역 언어는 아직 미완료다.

현재 공통 UI/언어/테마 검사 9개 통과. 테마 초기화 파일의 서식 차이로 이전 동일 문자열 검사가 실패했으며, 실제 제공 스크립트의 테마 선택 및 저장소 키 동작을 10가지 조합과 browser API 부재 상황에서 비교하도록 보완했다. CSP의 개발/운영 구분 검사도 유지했다. 사용자 담당 이름 변경은 수정하지 않았다.
