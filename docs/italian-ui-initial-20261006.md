# 이탈리아어 UI 카탈로그 (2026-10-06)

영어 기준 1437개 키 전체에 이탈리아어 문구를 연결했다. it-IT와 it-CH는 같은 카탈로그를 사용하며, 언어 선택창의 부분 번역 표시는 해당 언어에서 제거된다. 다른 Linux 언어의 미번역 fallback은 유지한다.

로그인, 설치, 공통 메뉴, 터미널, 보안·sudo, 로그·감사, nginx 설명과 코드 편집, Certbot·cron, 데이터베이스 설정 및 백업·복구 문구를 포함한다. 명령·경로·인증 방식 이름과 변수 placeholder를 보존했다.

관련 번역·PostgreSQL 설명·설정 GUI 검사 20개 성공. 모든 이탈리아어 키가 영어 카탈로그와 일치하고 비어 있지 않으며, 번역 결과에 한국어가 남지 않고 placeholder가 유지됨을 확인했다. 실제 브라우저에서 이탈리아어의 부분 번역 표시가 사라지고 nginx 설정 설명·공통 조작이 이탈리아어로 표시됨을 확인했다. 해당 검사 탭의 콘솔 error 로그는 0개였다. 검사 후 한국어로 복원하고 임시 탭을 닫았다.

증거 화면: `/tmp/tastedev-nginx-italian-complete-20261006.jpg`.

이는 현재 카탈로그의 키 전체 번역과 위 범위의 검증이다. 원어민 검수나 모든 화면의 문맥 검수를 완료한 것은 아니며, 모든 Linux 언어 지원 또는 전체 시스템 목표 완료를 의미하지 않는다. 시스템 설정은 변경하지 않았다.
