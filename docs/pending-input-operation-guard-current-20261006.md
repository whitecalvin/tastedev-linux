# 미반영 입력의 운영 검토 차단 — 2026-10-06

PostgreSQL·Redis·MariaDB IDE에서 pendingGuiFields 또는 pendingSettingInputs가 있으면 검수/적용 검토 팝업을 열지 않는다. 이미 직렬화된 이전 코드를 운영 계획에 전달하지 않고 설정 탭으로 전환해 미반영 입력 안내를 표시한다. 입력을 모두 수정하면 검토를 재개하며 안내를 해제한다. 코드 화면에도 미반영 입력 안내를 표시해 코드와 폼이 다른 상태임을 알린다.

설정 복원 후 편집기 자동 갱신은 hasUnsavedIdeRecord로 판단한다. 코드가 저장 기준과 같아도 미반영 입력이 있으면 코드/입력을 보존하고 조회한 운영 파일 버전만 갱신한다. 상단 백업은 계속 현재 운영 파일을 대상으로 한다.

안내를 한국어와 기존 11개 외국어 카탈로그에 추가했다. 번역 검사에서 발견한 기존 Node 서비스 조회 오류의 누락 번역도 채웠다. 카탈로그마다 1456개 문구이며 이는 선택 가능한 모든 Linux 언어의 번역 완료를 뜻하지 않는다.
