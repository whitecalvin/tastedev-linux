# Node.js IDE 연결별 화면 유지

API 또는 연결 상태가 교체된 첫 렌더에서 이전 앱 목록·디스크 환경 파일 목록·선택한 설정 화면·오류 안내를 숨긴다. useEffect 초기화보다 먼저 적용하므로 이전 서버 목록이 새 연결의 앱 관리 컴포넌트에 전달되지 않는다. 목록과 선택에는 각각 조회/선택한 연결 객체를 기록한다. 오래된 트리 노드 클릭과 자식 목록 갱신도 현재 연결과 일치할 때만 반영한다.

새 연결 자식이 목록을 전달할 때 이전 연결의 workspace를 합치지 않는다. 같은 연결의 정상 갱신에는 현재 workspace를 보존한다. 기존 SSR 초기 목록은 불필요하게 다시 요청하지 않으며, 미저장 사용자 환경 파일 초안도 지우지 않는다.

실제 JSX를 컴파일한 Node IDE·앱 탭과 로그, manager 상태 관련 8개 검사 통과. 연결 해제 및 API 함수 교체 시 effect 이전의 목록/선택 숨김, 이전 노드 클릭 무시, 늦은 이전 조회 무시, SSR 초기 목록 유지, 미저장 파일 보존을 확인했다. 브라우저의 실제 연결 교체 수용은 별도 미완료다. 운영 앱/서비스 변경은 하지 않았다.
