# 관리자 오류 한국어 안내

알려진 helper 오류 119개와 접두어 안내 3개를 한국어로 연결했다. nginx·PostgreSQL·MariaDB·Redis·서비스·sudo·프로세스 잠금에서 잘못된 값, 원본 변경, 권한, 확인 누락, 진행 중 작업을 구분한다. 검증된 오류 응답의 상태 코드와 프로토콜 검사를 유지한다. 알 수 없는 오류와 기존 한국어는 변경하지 않는다.

원복 실패 메시지와 폴더 권한 메시지에 붙은 원시 진단은 한국어 안내에 넣지 않는다. 실행 기록·코드 원문을 변경하는 기능은 아니다.

자체 임시 복사본 검사 13개와 이후 영어 Redis 오류의 실제 조각 전송 사례 추가 검사 1개가 통과했다(중복 포함). 시스템 상태를 건드리지 않는 비관리자 helper 거부도 한국어 403 안내로 확인했다. 최신 384개 소스 Next.js 빌드가 통과했다.

원본 helper 이름과 내용은 유지했고 자체 복사본을 정리했다. 실제 브라우저 실패 표시, 원본 전체 회귀, 설치 운영 수용과 전체 한국어 완성은 아직 증명되지 않았다. 다국어 추가 작업은 하지 않았다.
