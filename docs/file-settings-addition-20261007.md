# 일반 설정 추가 폼 보존

PostgreSQL·Redis·MariaDB의 아직 추가하지 않은 이름·값·그룹·값 없는 옵션을 파일별 미반영 입력에 저장한다. MariaDB의 특정 그룹 화면에서는 그룹별 키를 사용하여 다른 그룹에 입력을 섞지 않는다.

코드 편집으로 기존 줄이 변경되거나 삽입되어도 추가 폼은 유지한다. 성공한 추가는 해당 폼 입력만 정리하며 기존 행 미완성 값과 다른 그룹 폼은 보존한다. 잘못된 이름·값의 추가 실패는 입력을 남긴다. 입력을 모두 기본값으로 되돌리면 해당 미반영 상태를 제거한다. 미반영 폼은 기존 파일 전환/페이지 이동 보호와 검수 차단에 포함된다.

실제 컴파일 컴포넌트의 파일·그룹 전환과 코드 변경·성공/실패 정리를 포함한 관련 검사 9개 통과. 이전 검사에서 전체 콜백을 코드 변경으로 계산하거나 내부 hook 번호를 읽고 있었던 부분은 코드 변경과 pending 변경을 구분하고 렌더링한 입력값을 확인하도록 수정했다. 매 입력 후 새 화면에서 다음 값을 입력하도록 맞췄다.

현재 384개 소스의 빌드와 실제 한국어 브라우저 확인도 완료했다. PostgreSQL·Redis·MariaDB에서 설정/코드 보기 전환 후 추가 입력이 유지되고, 추가 전 원본 코드가 그대로이며, 성공한 추가만 코드에 반영되고 폼이 초기화되는 것을 확인했다. PostgreSQL은 다른 파일 전환 확인에서 입력을 유지한 뒤 원래 파일로 돌아오는 흐름도 확인했다. MariaDB는 `[client]`에서 서버 그룹 입력이 보이지 않고 `[mariadbd]`로 돌아오면 복원되는 것을 확인했다.

각 검사는 격리된 로컬 서버와 자체 설정 파일에서 수행했다. 코드 초안 원복·로그아웃·원본 파일 무변경·임시 서버 정리를 확인했다. 실제 운영 파일 적용은 이번 범위에 포함하지 않는다.
