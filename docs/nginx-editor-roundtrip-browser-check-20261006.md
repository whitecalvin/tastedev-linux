# nginx 코드와 설정 왕복 편집 확인

로그인된 개발 브라우저의 nginx IDE에서 nginx.conf 노드를 선택하고 코드 보기로 전환했다. 화면의 원래 원문을 보관하고 `worker_processes`를 첫 줄로 이동하며 값 `auto`를 `2`로 변경한 뒤 '초안에 반영'을 실행했다. 설정 탭에서 worker_processes가 1행, user가 2행으로 표시되고 값 2를 확인했다.

worker_processes의 '내용 비우기'는 입력칸을 비우며 설정 행을 유지했다. 이 동작은 로컬 입력 편집으로 초안 원문을 자동 변경하지 않는다. 초안 반영 없이 탭을 변경하면 기존 값으로 돌아왔다. 이는 영속적인 설정 해제 기능이 아님을 확인했다.

GUI에서 값을 3으로 입력하고 해당 항목의 '초안에 반영'을 실행한 뒤 코드 보기에서 첫 줄 worker_processes 3을 확인했다. 보관한 원래 원문을 다시 초안에 반영하여 user/worker_processes/worker_cpu_affinity 순서 및 www-data/auto/auto 값을 복원했다.

운영 적용·작업 폴더 저장·다운로드·서비스 제어는 실행하지 않았다. 이 증거는 브라우저 초안의 명시적인 반영과 왕복 순서/값 동기화에 한정한다. 탭 전환 전 미반영 입력 보존 및 영구적인 항목 해제는 별도 개선 대상으로 남는다.
