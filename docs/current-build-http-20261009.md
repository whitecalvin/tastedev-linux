# 현재 소스 운영 빌드·HTTP 확인

현재 397개 소스에서 공통 IDE 헤더 44px·아이콘 32px 및 데몬 한국어 상태/조회 실패 안내 변경을 포함한 Next.js 운영 빌드가 성공했다. 빌드 중 소스 변경은 없었다. 같은 빌드로 보호 페이지 11개, 로그인/재시작 세션 유지/기한 만료 이동/새 로그인/로그아웃/Origin 차단, Certbot 방식별 발급 없는 미리보기, 실제 PTY 한글·이모지/SSE·완료 감사를 포함한 HTTP 검사 16개 그룹을 확인했다. 자체 HTTP 서버와 계정은 검사 스크립트가 정리했다.

첫 빌드는 종료 1/빈 로그로 실패했다. 다음 읽기 명령에서는 sandbox 임시 mount의 quota exceeded가 실제 관찰됐다. 첫 빌드 실패 원인을 빈 로그만으로 확정하지 않는다. /proc 프로세스 cwd와 소스 project 표식을 확인한 사용하지 않는 이 작업의 이전 빌드 두 개만 정리했고, 로그·소스 해시 snapshot은 보존했다. 그 뒤 새 빌드가 성공했다. 첫 실패 기록도 보존하며 재시도 성공으로 덮어쓰지 않는다.

결과는 `.runtime/verification/source-build-2026-10-08T17-44-27.568Z/result.json`, `.runtime/verification/production-http-2026-10-08T17-44-51.195Z/result.json`이다. 이 결과는 실제 설치 Tauri 전체 GUI·공급자 AI 응답·최종 배포 수용의 완료를 뜻하지 않는다. sudo 켜기 적용 승인은 여전히 대기하며 DEB 생성·검증을 수행하지 않았다.
