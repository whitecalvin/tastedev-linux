# 패키지 검색 도구 정렬 및 내부 스크롤 확인

개발 브라우저 `/packages`에서 검색 입력·CustomSelect·초기화 버튼의 높이는 모두 32px이나, 버튼이 다른 입력보다 14px 위에 표시됐다. 페이지별 `.package-filter-bar`의 `align-items: center`가 공통 하단 정렬을 덮어쓰는 원인이었다. 이 페이지 규칙을 `flex-end`로 수정했다.

실제 브라우저의 스타일 갱신 뒤 세 컨트롤의 높이 32px, y 위치 188px가 모두 일치했다. 1280×720 뷰포트에서는 document 크기가 뷰포트와 일치했고, `.management-body`만 clientHeight 526px / scrollHeight 740px의 내부 스크롤 영역을 가졌다. 상단과 왼쪽 아이콘 메뉴는 본문 밖에 유지됐다. 확인 뒤 뷰포트 임시 설정을 해제했다.

운영 패키지 설치, 서비스 변경 또는 배포 작업은 수행하지 않았다. 이번 확인은 패키지 화면 검색 도구 정렬과 본문 스크롤에 한정한다.
