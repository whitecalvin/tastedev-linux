# 세션 만료와 로그인 복귀 URL

2026-10-06

SSR 보호 화면 및 열린 콘솔의 클라이언트 401/미인증 처리에서 URL 검색 조건을 보존한다. 로그인 복귀 경로는 허용된 내부 라우트만 허용하며 외부 origin, 허용되지 않은 경로, fragment는 유지하지 않는다. 잘못된 /ide package 값은 제거한다. 반복된 검색 조건도 유지한다.

관련 컴포넌트/SSR/로그인 검사 15개 성공. 현재 소스 349개를 복사해 Next.js 운영 빌드 성공, 복사 전후 SHA-256 동일 및 검사 후 원본과 동일 확인.

현재 운영 빌드의 임시 인증 DB에서 세션 만료 시각을 1.5초 후로 지정하고 그 시각을 넘긴 실제 HTTP 요청을 검사했다. 만료 직전에는 요청하지 않아 Better Auth의 자동 갱신이 검사를 무효화하지 않도록 했다. 만료된 쿠키로 11개 보호 화면과 각 화면의 반복 query 조건이 로그인으로 이동하고, /api/cron은 401을 반환했다. 재로그인 후 새 쿠키가 발급되며 원래 nginx 경로와 query로 복귀했다. 기존 로그인·재시작 유지·외부 origin 차단·로그아웃 포함 HTTP 10개 시나리오 성공.

HTTP 검사 서버 및 임시 인증 DB는 종료/삭제됐다. 실제 사용자 계정·개발 서버·운영 서비스는 변경하지 않았다. 웹 화면에서 자연 만료 후 사용자 조작 흐름과 설치 환경 수용 검사는 남아 있다.
