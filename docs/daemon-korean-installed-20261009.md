# 데몬 한국어 상태·진단 안내

현재 원래 GUI에서 systemctl 상태 코드를 실행 중·중지·실패·알 수 없음 등 한국어로 표시한다. 빈 SubState/UnitFileState 때문에 남던 구분점도 제거했다. systemctl 미설치 또는 조회 실패는 한국어로 설명하고 외부 명령의 원본 진단은 접힌 진단 내용에 보존한다. 서비스 ID·실행 요청·필터의 원시 상태 값은 유지했다.

관련 기존 서비스 제어·목록 갱신·SSR 초기 상태·패키지 링크·필터 검사 5개 파일이 통과했다. 103번 자체 Docker 설치 모드 원래 GUI에 변경 파일 하나를 SHA 확인 후 전달했다. 실제 데몬 화면에서 한국어 알 수 없음 6개/미설치 설명 6개/원본 진단 6개 보존, 브라우저 오류 0, 문서 바깥 스크롤 없음 확인. 이 컨테이너에는 systemctl과 관리 대상 패키지가 없으므로 실제 서비스 제어 성공 증거로 확대하지 않는다.

대시보드·데몬·로그·복구·보안·감사·패키지·터미널 8개 route는 공통 상단 56px과 문서 바깥 스크롤 없음을 확인했다. 터미널은 서버 기능 비활성 상태로 레이아웃만 확인했다. 이 결과가 전체 IDE나 설치 Tauri 수용을 대신하지 않는다. 자체 검수 탭 64는 닫았으며 sudo 적용 승인 탭 63은 유지했다. HMR로 초기화된 미리보기는 같은 nginx-check 한 명령의 NOPASSWD 미리보기로 다시 준비했으며 규칙은 적용하지 않았다.

증거는 `.runtime/verification/daemon-korean-installed-20261009/`에 있다. 최종 배포 패키지 생성·검증은 수행하지 않았다.
