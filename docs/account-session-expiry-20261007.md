# 계정 화면의 세션 만료 이동

계정 비밀번호 변경 화면은 공통 관리 API와 별도의 인증 API를 사용한다. 기존 구현은 만료된 세션의 401도 한국어 오류 문구만 표시했다. 인증 API에서 `SESSION_EXPIRED`를 전달하고 계정 화면은 이 코드와 401이 함께 있는 경우 입력한 비밀번호 세 값을 지운 뒤 공통 로그인 이동을 호출한다. 공통 이동은 초안과 상태를 정리하고 `/login?next=%2Fsecurity`로 한 번만 이동한다.

현재 비밀번호가 틀려도 인증 API는 401을 반환하므로 상태 코드만으로 이동하지 않는다. 유효한 세션의 비밀번호 오류에는 만료 코드를 붙이지 않으며 화면의 오류 안내와 재입력을 유지한다. 요청 실패·중복 제출 보호도 유지한다.

관련 검사 11개 통과. 실제 자체 검사 계정의 유효 세션·잘못된 비밀번호·비밀번호 변경 후 모든 기존 세션 종료·보안 쿠키·세션 갱신, 컴파일한 계정 화면의 만료 이동/입력 정리·잘못된 비밀번호 안내, 공통 화면의 한 번만 이동과 `/security` 복귀 경로를 확인했다. 실제 사용자의 계정과 비밀번호는 변경하지 않았다. 브라우저 비밀번호 입력 수용 검사는 수행하지 않았다.

증거: `.runtime/verification/account-session-expiry-20261007/result.json`, 같은 디렉터리의 `test.log`. 이번 수정 전 공통 기능 회귀는 174개 중 171개 통과·3개 격리 경로 조건으로 미실행·실패 없음이며 별도 결과 `.runtime/verification/korean-flow-regression-20261007/result.json`에 범위를 남겼다. 미실행 항목을 통과로 계산하지 않는다.

초기 격리 경로 조건으로 미실행한 보안 검사 3개를 조건에 맞는 자체 임시 경로에서 재개했다. 해당 두 파일의 39개 검사 전부 통과·미실행 없음(이전 검사와 중복 포함). 결과 `.runtime/verification/korean-flow-isolation-followup-20261007/result.json`. 운영 보안 정책과 sudo는 변경하지 않았다.

최신 384개 소스의 Next.js 빌드 통과: `.runtime/verification/source-build-2026-10-06T21-39-08.421Z/result.json`. 최초 빌드의 쓰기 할당량 실패는 자체 이전 빌드 증거를 보존하고 정리한 후 재개했으며 기록은 `temporary-build-cleanup-20261007-12/result.json`에 남겼다. 배포 패키지는 생성하지 않았다.
