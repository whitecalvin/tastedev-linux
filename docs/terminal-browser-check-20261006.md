# 개발 터미널 실제 브라우저 확인

현재 개발 서버 `http://127.0.0.1:8787/terminal`에서 로그인된 브라우저로 확인했다.

- 터미널 메뉴 진입 후 기본 Bash 세션이 자동으로 열리고 입력 필드에 포커스가 이동했다.
- `printf 'terminal-check: '; id -un`을 입력하고 Enter로 실행하여 `terminal-check: whitecalvin` 출력을 화면에서 확인했다.
- `printf '%s\n' '한글 입력 확인'`의 명령과 한글 출력이 화면에 표시됐다. 자동 입력 검사는 실제 OS 한영 전환 및 IME 조합 이벤트 검사가 아니다.
- 설정 팝업에서 현재 사용자 whitecalvin, 프로젝트 `.runtime/workspace` 작업 폴더, 기본 셸 `/bin/bash`, CLI 프리셋과 실행 제한 시간 선택을 확인했다. 설정값은 변경하지 않았다.
- 새 터미널 2를 생성하여 `second-tab-check` 출력을 확인했다. 터미널 1로 돌아왔을 때 기존 영문/한글 출력이 보존됐고 터미널 2의 출력은 섞이지 않았다. 검사 뒤 새로 만든 터미널 2의 닫기 동작을 실행했다.
- 1757×1292 화면에서 문서의 scrollWidth/scrollHeight가 뷰포트와 일치했다. 왼쪽 아이콘 패널을 제외한 본문 전체를 어두운 터미널이 채웠고 도구 버튼은 상단에 표시됐다.

운영 파일·서비스·계정 권한은 변경하지 않았다. 이 증거는 현재 개발 환경의 기본 세션, 명령 입력/출력, 탭 전환 및 화면 크기에 한정한다. 실제 OS IME, SSH 연결, CLI 대화형 프로그램, 배포 설치 환경은 별도 확인 범위다.
