# Node 서비스 제어 GUI 요청 보호

이전 API/앱/권한의 실행 확인 함수가 남아 있으면 React effect 실행 전에도 요청을 전송했고, 완료 이후 같은 확인 함수 호출로 중복 실행할 수 있었다. 실제 컴파일된 컴포넌트 회귀에서 기존 3개 성공·추가 7개 실패로 재현했다.

렌더 시점의 연결·앱·정책·stop-only 범위를 비교하고 unmount/disabled 상태를 확인한다. 승인 객체를 작업 시작 전에 1회 소모하며 취소 후 같은 작업을 선택하더라도 기존 승인과 구분한다. 이전 범위의 확인/결과를 새 화면에 표시하지 않는다. 기존 중복 대기 차단·상태 재조회 대기·재조회 실패 안내는 유지했다.

최종 서비스 제어 및 인접 설정 변경/백업 GUI 검사 32개 성공, 건너뜀 0. 기존 정적 테스트도 실제 아이콘 선택→확인 흐름과 지속 hook ref를 사용하도록 정정했다. 초기 sandbox runner 종료와 중간 mock 누락 실패를 보존했다. 원래 브라우저/인증 API/실제 helper 전체 수용 검수는 별도 남는다.

증거: `.runtime/verification/node-control-context-20261008/result.json` 및 before-host/after/final 로그.
