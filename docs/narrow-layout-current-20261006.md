# 좁은 화면 공통 레이아웃 — 2026-10-06

실제 개발 화면에서 640×640일 때 패키지 설치 페이지의 왼쪽 작업 분류 패널이 사라지는 문제를 확인했다. 원인은 기존 700px 이하 CSS가 `.admin-rail`을 숨기는 규칙이었다. 주 메뉴가 없는 패키지·터미널 화면은 다른 화면으로 이동할 수 없었다.

공통 CSS에서 좁은 화면에도 48px 작업 분류 패널을 유지한다. 현황·도구의 보조 메뉴는 이 패널 옆의 가로 메뉴로 배치하고 링크/버튼을 32px 높이로 맞췄다. 기존 링크 스타일 때문에 가로 메뉴가 세로로 잘리던 문제도 수정했다. nginx 설정 헤더에 상속되던 세로 정렬을 가로 정렬로 수정해 상태는 왼쪽, 아이콘 동작은 오른쪽 한 줄을 유지한다. 보조 메뉴 없는 터미널은 56px 헤더 바로 아래에서 시작하며, IDE는 보조 메뉴 높이를 뺀 본문 높이를 사용한다. RTL에서는 패널과 본문 여백을 반대로 적용한다.

브라우저 확인:
- 960×640 패키지 화면은 기존 두 열 배치와 본문 내부 스크롤 유지.
- 640×640 패키지 화면에서 네 주 메뉴가 보이고 현황으로 실제 이동.
- 현황에서 로그 보조 메뉴로 실제 이동. 여섯 링크 높이 모두 32px, 보조 메뉴 clientHeight/scrollHeight 모두 45px.
- 로그 화면 document 크기 640×640, 본문 왼쪽 48px·하단 614px. 페이지 전체 넘침 없이 본문 영역 사용.
- nginx IDE 화면 document 크기 640×640, 본문 왼쪽 48px·상단 102px·하단 614px. 파일 트리와 미선택 안내가 동시에 표시된다.
- 터미널 화면 document 크기 640×640, 본문 상단 56px·왼쪽 48px. 터미널 host 너비 592px·높이 551px. 기존 OS 사용자 셸 프롬프트 표시. 이 점검에서는 명령을 입력하지 않았다.

증거 화면: `/tmp/tastedev-terminal-narrow-layout-20261006.png`.

OS 한글 입력기 실사용, 운영 변경 및 전체 모바일 화면 합격을 주장하지 않는다. 점검용 탭과 셸을 종료하고 브라우저 viewport override를 복원한다.
